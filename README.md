
# SwitchMapExample

Bu proje, Android uygulamalarında \`Switch\` bileşenleri ile çalışmayı göstermektedir. 
Uygulama, konum servislerini açma/kapama işlemlerini ve belirli ayarların görünürlüğünü yönetir.

## 📌 Özellikler

- **Konum Servisleri Aç/Kapat**: Kullanıcı ana konum servisini açtığında, \`get location\` ve \`send location\` seçenekleri görünür hale gelir.
- **Dinamik Görünürlük**: \`Switch\` butonlarının durumu değiştikçe ilgili bileşenlerin görünürlüğü de değişir.
- **Toast Mesajları**: Kullanıcının seçimlerine bağlı olarak ekran bildirimleri (\`Toast\`) gösterilir.
